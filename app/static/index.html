      Dependencies

      Links run project to project — which whole piece of work has to land before another can start. Order inside a project is yours to arrange; nothing checks it.

        All projects

        One column per week, labelled with the Monday it starts. The window shows up to six months at a time — pick a length, or Custom… for your own range. Drag a bar sideways to move that phase; it snaps to a week column, hold Alt to nudge it by single days. Nothing else reschedules itself — a project waiting on this one only starts warning.

        Not placed yet

        Projects you have estimated but not dated. Drag one onto the chart to start it that week — its undated phases are laid out back to back from there, in the order you arranged them. Phases that already have dates keep them. A drop can be undone until you reload the page.

        Cross-project dependencies

        Finish to start, in the order they were linked. A link marked V2 is one where the later project already begins before the earlier one finishes.

          Team map

          Your department at the centre, tracks around it, projects on the outside. Write a track as Source expansion / Metrics to split it into a subtrack. Circle size is total effort points; each label shows phases done and what lands next. Dashed circles are future directions — ideas nobody has committed to yet. Point at a project to dim the map down to it and whatever it is linked to, with arrows running predecessor → successor. Click a project to open it.
