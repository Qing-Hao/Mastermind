## Status

Use a simple workflow:

Use `Blocked` when work cannot proceed because of a dependency or issue.

## Definition of Done

A task is Done when:

- [ ] Implementation is completed
- [ ] Code has been reviewed
- [ ] Testing is completed
- [ ] Required documentation/configuration is completed
- [ ] Changes are merged
- [ ] Release/deployment is completed where applicable
- [ ] Product Owner accepts the outcome where applicable
