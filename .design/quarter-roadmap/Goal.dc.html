What it costs the schema
CREATE TABLE IF NOT EXISTS quarter_goal (
    id       INTEGER PRIMARY KEY AUTOINCREMENT,
    -- '2026-Q3'. The period is the key: no start date, no end
    -- date, nothing to disagree with the phases below it.
    period   TEXT NOT NULL UNIQUE,
    goal     TEXT NOT NULL DEFAULT '',
    target   TEXT NOT NULL DEFAULT '',
    -- The one stored state, and deliberately a tick rather than
    -- an enum -- the same decision milestone.achieved carries.
    achieved INTEGER NOT NULL DEFAULT 0 CHECK (achieved IN (0, 1))
);
Five columns, one table, no foreign key. Joins to nothing, so a project moving quarter costs no write. Rides /api/export like any other table — and carries no sso_ prefix problem, because it holds no secret.
What it must not become
NN 4 No project_id and no join table. The moment a project is assigned to a quarter there are two answers to when it lands, and the dates stop being the record.
NN 7 No owner, no created_by, no per-person view. A quarter goal is the department's; the gate stores nothing about who wrote it.
NN 8 No points total on the header. A per-quarter sum is a points-per-day constant in disguise, which the capacity design rules out. Project and checkpoint counts are safe.
NN 1 Writing a goal reschedules nothing. It is a sentence about a period, and the plan under it is untouched by it.
NN 5 Nothing derives achieved from the work below. Someone presses it, the same way promotion works.
