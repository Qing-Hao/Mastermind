Everybody's count moves together
The socket already carries {"type":"changed"} on every write, and every open page re-reads on it. The count is read off that re-read — no new message type, no push, nothing queued for a page that is not open.
Midnight is the one gap
Nothing writes at midnight, so a page left open overnight would hold yesterday's count. One re-check when the date rolls, on the page's own clock — not a timer on the server.
