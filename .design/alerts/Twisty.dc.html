Top of the page, back at the start of the window, and the twisty you pressed no longer exists — so the keyboard is on <body>.
The fix — hold the three things the redraw drops
1Page offset. Read window.scrollY before the redraw, set it back after — the chart is taller again by then, so nothing is clamped.
2Window offset. Same for #portfolio-scroll.scrollLeft, or you open a lane and lose the month you were reading.
3Focus. The new twisty for that project takes focus back, so Enter-Enter folds and unfolds one lane instead of falling off the page.
Restore synchronously, in the same call — not in a setTimeout. Anything asynchronous is a visible jump and back.
Why not the smaller change
Redrawing only the lane that opened would avoid the problem outright, but the lane's height feeds the grid body and the today line above it, so a partial redraw is a second layout path to keep in step with the whole one. Save and restore is three lines and one function; the surgical version is a rewrite of renderPortfolio that nothing tests.
Same wrapper covers the other redraws on this tab — the window bar, a drag that drops, a write arriving over the socket. Every one of them is chart.innerHTML = "" today.
