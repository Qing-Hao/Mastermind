Columns map by header name

  • Task→ Task
  • Priority→ Priority

  • Status→ Status
  • Reviewer→ Reviewer

Case-insensitive, trimmed. A target column the source has no name for stays empty. Actual is deliberately not carried — it is time already spent in a fortnight that is over.

Two names, one column

§4 heads its body Work where §3 heads it Task, and calls the HIGH / MEDIUM / LOW column Commitment where §3 calls it Priority.

  • Task→ Work
  • Priority→ Commitment

Those two pairs, and nothing else. A §3 row carried into §4 maps all seven and drops nothing. Any other disagreement is dropped and named in the toast, never silently — and a column that was empty is not named, because nothing was lost.
